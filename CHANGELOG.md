# Changelog

All notable changes to this package are documented here. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v1.0.0] - 2026-11-06

### Added

- Public portfolio index and case-study pages.
- Works on its own with a publishable model and migration, or alongside `mikepagedev/filament-portfolio`.
- Configurable URL prefix, middleware, on/off switch and layout component.
- Configurable screenshot disk.
- Configurable page wording and contact prompts.
- Contact prompts that hide themselves when the site has no contact route.
- Publishable views.
